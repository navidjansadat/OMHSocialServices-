# OMH Social Services — Render Free + Supabase

This version does not require a Render Persistent Disk.

## Deploy
1. Create a Supabase project.
2. Get the Postgres connection string from Supabase: Connect → Session pooler (recommended for hosted/serverless deployments) or direct connection where appropriate.
3. Get `SUPABASE_URL` and the `service_role` key from Project Settings → API.
4. Push this project to GitHub.
5. Create a Render Web Service from the repository. `render.yaml` uses the free plan.
6. Set `DATABASE_URL`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, and a strong `ADMIN_PASSWORD`. `SESSION_SECRET` is generated by Render when Blueprint settings are applied.

The server creates its PostgreSQL tables on first startup and creates the public `omh-uploads` storage bucket if it does not exist. Uploaded images are stored in Supabase Storage instead of the Render filesystem.

Never expose `SUPABASE_SERVICE_ROLE_KEY` in frontend code or commit it to GitHub.
